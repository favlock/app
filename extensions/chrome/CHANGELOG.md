# Chrome extension changelog

## 1.7.0 — September 1, 2026

Minimum supported FavLock dashboard version: **1.7.0**.

- Connect through FavLock's protected dashboard flow, reusing the signed-in and unlocked account when available.
- View the extension connection status and disconnect it from extension settings.

## 1.6.0 — August 28, 2026

- Aligned the extension version with the FavLock 1.6.0 app release. No extension behavior changes.

## 1.5.1 — August 27, 2026

Recommended FavLock dashboard version: **1.5.1** for the updated reconnection experience.

- Improved session renewal and reconnection handling without clearing saved local account data.
- Security and reliability improvements.

## 1.5.0 — August 26, 2026

Minimum supported FavLock dashboard version: **1.5.0**.

- Updated compatibility for the FavLock 1.5.0 release.

## 1.4.2 — August 25, 2026

- Kept the extension connected and unlocked when session renewal temporarily fails.

## 1.4.0 — August 22, 2026

Minimum supported FavLock dashboard version: **1.4.0**.

- Updated the FavLock name and production dashboard/API endpoints.

## 1.3.1 — August 19, 2026

- Updated compatibility for the FavLock 1.3.1 release.

## 1.3.0 — August 18, 2026

Minimum supported FavLock dashboard version: **1.3.0**.

- Added account connection with Google or email.
- Added extension unlocking with a saved passkey, uploaded recovery-key file, or manually entered encryption key.

## 1.2.1 — August 17, 2026

- Fixed production connection and pairing URLs so FavLock consistently uses the production dashboard and official Chrome Web Store identity.

## 1.1.0 — August 17, 2026

Minimum supported FavLock dashboard version: **1.2.0**.

- Sign in and unlock FavLock from the extension.
- Save pages with encrypted titles and URLs, then choose or create encrypted Collections, tags, and Lists.
- Recognize pages already saved in FavLock, preload their organization, and update them without creating another bookmark.
- Add a bookmark to multiple Lists without moving it from its Collection.
- Save the current window as a timestamped session while reusing existing bookmarks.
- Open Quick Save from the page context menu.
- See saved-page status in the popup and extension icon.
