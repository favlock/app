# Chrome Web Store screenshots

The five store-ready PNG files are exported at 1280 × 800 pixels in the
`screenshots` directory. All page names, domains, article text, and tags shown
in the images are fictional demo content.

The reusable HTML/CSS composition lives in `source`. Open
`source/index.html?shot=1` through `?shot=5` at a 1280 × 800 viewport to update
or re-export individual frames.

Screenshot order:

1. `01-quick-save.png` — quick save with Collections and tags
2. `02-search.png` — search titles, URLs, Collections, and tags
3. `03-tab-sessions.png` — save open tabs as a session
4. `04-reader-readspace.png` — Reader and web highlights
5. `05-import-bookmarks.png` — Chrome bookmark import

The `promo` directory contains the Chrome Web Store promotional artwork:

- `small-promo-tile-440x280.jpg`
- `marquee-promo-tile-1400x560.jpg`

Their reusable HTML/CSS source is in `promo/source`.
