# FavLock – Save, Search & Organize Bookmarks

## Short description

Save, search, and organize bookmarks with encrypted titles and URLs. Add Collections, tags, tab sessions, and article snapshots.

## Detailed description

FavLock keeps bookmarks and articles easy to capture, find, and organize without leaving Chrome. Connect with Google or email, then unlock your encrypted library with a saved passkey or recovery key.

Use Save mode to see whether the current page is already in FavLock, add it to a Collection, choose tags, or update an existing bookmark without creating another copy. Switch to Search to find saved bookmarks by title, URL, Collection, or tag and open them directly from the extension.

You can also import your existing Chrome bookmarks, save the current window as a tab session, turn an article into a clean reading view, or explicitly save selected text as an encrypted Readspace highlight.

Features:

- See when the current page is already saved
- Save new bookmarks or update their organization in place
- Choose or create encrypted Collections, tags, and Lists
- Search saved bookmarks by title, URL, Collection, or tag
- Save all open tabs as one session without duplicating existing bookmarks
- Open Quick Save from Chrome’s right-click menu
- Read articles in a focused, distraction-free view
- Adjust reader text size and choose a light, paper, or dark theme
- Save encrypted article snapshots to Readspace
- Save selected text as an encrypted highlight from Chrome’s right-click menu
- Restore saved highlights on websites you approve and remove them from the original page
- Import Chrome bookmarks with duplicate detection
- Optionally open FavLock in every new tab
- Build ordered Lists of videos and articles and track completion in FavLock

FavLock encrypts protected bookmark fields, including titles and URLs, along with Collection, tag, and List names before storage. Saved article snapshot content is also encrypted before it is stored or synced. Search runs locally in the extension after protected fields are decrypted on your device; your search query is not sent to a search service.

The extension uses current-page information when you open Quick Save, open-tab information when you save a tab session, article content when you choose Reader, and selected text when you explicitly save a highlight. Chrome asks for bookmark access only when you start an import and asks for access to the current website before enabling automatic highlight restoration there. You can turn webpage highlights off in extension settings to remove that website access. Protected data you choose to save is encrypted before it is sent to your FavLock account; Reader and highlight extraction run in your browser.

A FavLock account and unlocked library are required for saving, updating, and syncing content. Plan limits may apply.
